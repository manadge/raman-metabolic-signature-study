# Raman metabolic signature study

Code accompanying the scientific publication: *Metabolic signature study of* L. monocytogenes *and* V. parahaemolyticus *by Raman spectroscopy with the Raman-DIP method*.

**License:** MIT (see `LICENSE`)

## Overview

This repository contains the full analysis pipeline used in the study: from raw Raman spectra (exported as `.txt` by the spectrometer) to baseline-corrected, normalized spectra, through exploratory PCA, band-area ratios, and supervised classification of the metabolic signature of bacterial strains grown under deuterated conditions. Raw data and preprocessed data are not included, and are available from the corresponding author on request.

## Data format

Raw spectra are tab-separated `.txt` files, one per acquisition, with two columns: Raman shift and intensity. Filenames encode the experimental metadata, parsed with a regular expression:

```
<date>_<strain>_<deuterium_rate_preparation>_<growth_condition>_<exposure_time>_<acquisition_number>.txt
```

Example: `2026-11-15_EGDe_75D2O_control_shortexposure_01.txt`

## Pipeline

### 1. Preprocessing (preprocessing notebook)

- **Import and formatting**: all `.txt` spectra are loaded into a single DataFrame (rows = spectra, columns = Raman shifts), metadata parsed from filenames and joined to the data.
- **Baseline correction**: Asymmetric Least Squares (AsLS), with optional zero-recentering (`min`, `q1`, or `clip`). An IModPoly polynomial baseline is also available as an alternative.
- **Cosmic spike removal**: cross-spectrum median comparison (z-score threshold), flagged points replaced by linear interpolation.
- **Normalization**: per-spectrum normalization (`max`, `l1`, `l2`, `minmax`, or `snv`). The study uses L2 normalization.
- Preprocessed spectra are cached as pickles in `preprocess_saves/`.

### 2. Processing (processing notebook)

- **Window selection**: fingerprint region (600-1730 cm⁻¹) and C-D / C-H region (1800-3050 cm⁻¹) extracted separately.
- **PCA**: per-group principal component analysis with loadings inspection and score boxplots, with statistical comparison against the control condition (Shapiro-Wilk, Levene, t-test or Mann-Whitney).
- **Band ratios**: trapezoidal integration of the two windows and ratio of the C-D band area to the total area, per spectrum.
- **Classification**: grid-searched logistic regression (and optionally SVM, Random Forest, KNN, Decision Tree) to discriminate growth conditions, with normalized confusion matrices and feature-importance spectra (|coefficients| smoothed by Savitzky-Golay, peak detection on discriminant bands).

## Key parameters

| Step | Function | Main parameters |
| --- | --- | --- |
| Baseline | `als_baseline_zero_cor_df` | `lam=1e5`, `p=0.01`, `niter=10`, `zero_ref="clip"` |
| Cosmic removal | `remove_cosmics_multispectra` | `z_thresh=5.0` |
| Normalization | `spectral_normalization_df` | `norm="l2"` |
| Sampling | per-group `df.sample(n=35, random_state=42)` | |
| Classification | `gridsearch_logreg_dict` | 5-fold CV, accuracy scoring |

## Reproducibility

- Fixed random seeds throughout (`random_state=42`).
- Grid-search results are cached in `cache/` (delete the folder to recompute).
- Notebooks are published with cleared outputs; all figures can be regenerated by running the notebooks end to end.
